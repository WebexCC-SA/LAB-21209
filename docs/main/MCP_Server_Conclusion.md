In this section, you integrated an external **MCP Server** with your Webex Event Health AI Agent.

### Key Capabilities Implemented

- Created an **Agentic App** in the Webex Developer Portal
- Enabled and authenticated the MCP server in **Control Hub**
- Connected **get_pharmacy_locations** and **check_order_status** tools to your AI agent
- Tested pharmacy location lookup and order status tracking over voice and chat preview

This pattern allows you to extend your AI agent with reusable external tools — reducing duplicate flow logic and making it easier to maintain integrations across multiple agents.
